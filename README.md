# モンスタリア 星環の旅

ビルド済みゲームの配信用リポジトリです。

遊ぶ: https://hide121.github.io/monstaria/

iPhoneはSafariの共有メニューから「ホーム画面に追加」し、追加したアイコンから開いてください。タイトルの「記録を選ぶ」→「iPhone・オフライン準備」で、ダウンロード完了とセーブ移行を確認できます。

セーブは端末内に保存します。自動同期はありません。別端末から移すときはセーブJSONを「ファイル」に保存し、ホーム画面のアプリ内で読み込んでください。セーブJSONはこのリポジトリへアップロードしないでください。

開発版 0909p。実機での表示・操作と後半の難易度は調整中です。
