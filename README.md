# モンスタリア 星環の旅

ビルド済みゲームの配信用リポジトリです。

遊ぶ: https://hide121.github.io/monstaria/

iPhoneはSafariの共有メニューから「ホーム画面に追加」し、追加したアイコンから開いてください。タイトルの「記録を選ぶ」→「iPhone・オフライン準備」で、ダウンロード完了とセーブ移行を確認できます。

セーブは端末内に保存します。自動同期はありません。別端末から移すときはセーブJSONを「ファイル」に保存し、ホーム画面のアプリ内で読み込んでください。セーブJSONはこのリポジトリへアップロードしないでください。

開発版 0909s。実機での表示・操作と後半の難易度は調整中です。

セーブ取り込みは「① セーブJSONを選ぶ」でファイルを選択し、ファイル名を確認して「② 選んだセーブを取り込む」を押してください。主人公の顔アイコンを追加しました。

特性の解説、仲間・配合のランク表示、仲間からの装備変更、錬金限定12種を追加。通常の野生はB以下が中心で、Aは希少枠、S以上は通常出現しません。

クリア後の白銀の秘境、金属系3種、後半の希少遭遇、高経験値報酬、預かり所の経験値10%を追加しました。後半の通常敵も強化しています。
